DREHSCHEIBE – Dateien per Radmenü umwandeln
==========================================

INSTALLIEREN
1. Dieses ZIP komplett entpacken (Rechtsklick > Alle extrahieren).
2. "Installieren.bat" doppelklicken.
   - Falls Windows warnt ("Der Computer wurde durch Windows geschützt"):
     "Weitere Informationen" > "Trotzdem ausführen".
   - Die Installation lädt einmalig ca. 200 MB (Electron und ffmpeg) von GitHub.
     Das dauert je nach Internet 1 bis 5 Minuten. Keine Administratorrechte nötig.
3. Danach liegt "Drehscheibe" auf dem Desktop und im Startmenü.

BENUTZEN
- Bühne: Dateien ins Fenster ziehen. Strg gedrückt halten, Datei drücken,
  zum Format ziehen, loslassen. Ohne Tastatur: Datei kurz anklicken, dann Format anklicken.
  Mehrere Dateien mit Umschalt+Klick markieren = Stapel.
- Direkt auf dem Desktop / im Explorer (wie im Video):
  Haken bei "Strg + Klick auf Desktop und Explorer" (ist standardmäßig an).
  Strg gedrückt halten, auf eine Datei klicken und zum Format ziehen.
  Die Drehscheibe läuft dafür im Hintergrund (Symbol unten rechts im Infobereich).
- Rechtsklick-Menü: Haken bei "Rechtsklick-Menü" setzen, dann erscheint
  "Mit Drehscheibe umwandeln" (unter Windows 11 unter "Weitere Optionen anzeigen").
- Die neue Datei liegt neben dem Original. Klick auf die Fertig-Meldung öffnet den Ordner.

FORMATE
- Bilder: JPG, JPG 70 %, PNG, WEBP, BMP, TIFF, ICO, PDF, Halbe Größe
- Video: MP4, MP4 720p, MP4 HEVC, WEBM, MOV, AVI, MKV, GIF, MP3, Untertitel (SRT)
- Audio: MP3, M4A, WAV, OGG, FLAC
- Text: TXT, MD, HTML, CSV, JSON untereinander, dazu PDF
- Archive: ZIP, TAR, TAR.GZ
- Word/Excel/PowerPoint/ODT: nur wenn LibreOffice installiert ist (libreoffice.org)

BEKANNTE GRENZEN
- HEIC-Fotos (iPhone) kann ffmpeg meist nicht lesen.
- PDF als Quelldatei (PDF zu Word, PDFs zusammenführen) ist nicht eingebaut.
- Der Strg+Klick auf Desktop/Explorer fragt Windows nach den markierten Dateien.
  Bei Explorer-Tabs in Windows 11 kann das manchmal nichts finden. Dann die Bühne
  oder das Rechtsklick-Menü benutzen.

ENTFERNEN
"Deinstallieren.bat" doppelklicken.
